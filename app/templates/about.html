About the project

Smart Resume Analyzer with AI-Based Feedback is an Artificial Intelligence capstone project that demonstrates how rule-based AI and basic Natural Language Processing are used in recruitment and HR-technology platforms.

Problem statement

Many students create resumes without understanding:

  • ATS (Applicant Tracking System) requirements
  • Industry-relevant technical skills
  • Resume formatting standards
  • Keyword optimization
  • Role-specific expectations

Objectives

  1. Upload resumes in PDF or DOCX format
  2. Extract and process resume content
  3. Generate resume scores
  4. Check ATS compatibility
  5. Analyze role-based skills
  6. Receive smart improvement suggestions
  7. View analysis results on a dashboard

Technologies

  • Frontend: HTML5, CSS3, JavaScript, Bootstrap 5, Jinja2, Chart.js
  • Backend: Python 3.11, Flask, Flask-SQLAlchemy
  • AI/NLP: spaCy (tokenisation, lemmatisation, NER, noun chunks), NLTK (stopwords, tokenizer, frequency distributions, n-grams), regular expressions
  • Documents: PyMuPDF, python-docx, ReportLab
  • Database: SQLite (MySQL/PostgreSQL-ready via SQLAlchemy)
  • Testing / Deployment: pytest, Gunicorn, Render

AI / NLP methods

  • Text normalisation (Unicode, ligatures, bullets, whitespace)
  • Rule-based section-heading classification with synonym lists
  • Regex extraction of email, phone, URLs, degrees, years, grades, metrics
  • spaCy named-entity recognition for the candidate name
  • Keyword extraction with stopword removal, lemmatisation and frequency analysis
  • Alias and context-aware skill matching (e.g. "ML" counts only near ML context)
  • Weighted, explainable scoring and decision rules for recommendations

Scope limitations

As required by the specification, this prototype deliberately does not include deep-learning models, LLM training, complex recommendation engines, enterprise authentication or large-scale cloud architecture. Scores are transparent estimates; they are not produced by any commercial ATS. OCR for scanned resumes is not supported.
